VIM · 모드 기반 에디터

Vim의 전부는 ‘모드’다

명령 수십 개를 외울 필요 없다. 지금 내가 어느 모드에 있는지만 항상 알고 있으면 된다 — 나머지는 그 안에서 쓰는 단축키일 뿐이다.

Normal 모드 (기본값)

파일을 열면 항상 이 모드로 시작한다. 글자를 치면 타이핑되는 게 아니라 ‘명령’으로 해석된다 (예: j는 아래로 이동). 이동·삭제·복사·저장 같은 명령은 전부 여기서 친다.

Insert 모드 (타이핑)

i를 눌러야 들어간다. 여기서만 글자가 실제로 입력된다. 한글은 평소 쓰던 입력기(IME)가 그대로 작동한다 — 별도 설정 필요 없음. 다 썼으면 Esc로 Normal로 돌아간다.

헤매면 무조건 Esc. 어느 모드에 있든 Esc를 누르면 Normal 모드로 돌아온다. 화면에 이상한 글자가 찍히거나 명령이 안 먹히면, 십중팔구 지금 모드를 헷갈린 것이다 — Esc부터 누르고 다시 생각할 것.

지금 당장 쓰기 시작하는 법

이 다섯 단계만 알면 오늘부터 Vim으로 쓸 수 있다

1. 파일 열기

터미널에서 vim cache_city/원고/1장_히트율_99.7%.md 입력 후 Enter.

2. 쓰기 시작

i를 누른다 (화면 아래 -- INSERT --가 뜨면 성공). 이제부터 치는 대로 글자가 입력된다.

3. 쓰기 멈출 때

Esc를 눌러 Normal 모드로 돌아간다. 이동·저장 같은 명령은 Insert 상태에서는 먹히지 않는다.

4. 저장

Normal 모드에서 :w 입력 후 Enter. 화면 맨 아래에 명령이 입력되는 줄이 뜨는 걸 볼 수 있다.

5. 저장하고 끝내기

Normal 모드에서 :wq 입력 후 Enter. 저장과 종료를 한 번에 한다.

자주 하는 실수 · :wq를 쳤는데 안 꺼지고 이상한 반응이 온다면, 아직 Insert 모드일 수 있다 — Esc를 먼저 누르고 다시 :wq를 입력할 것.

명령동작

gg / G문서 맨 처음 / 문서 맨 끝으로 이동
{숫자}G해당 줄 번호로 이동 (예: 10G → 10번째 줄)
Ctrl-f / Ctrl-b한 화면 아래로 / 위로 스크롤
/단어 + Enter아래 방향으로 ‘단어’ 검색
n / N검색한 단어의 다음 위치 / 이전 위치로 이동

명령동작
i / a현재 글자 앞 / 뒤에서 Insert 모드 시작
I / A줄 맨 앞 / 맨 끝에서 Insert 모드 시작
o / O아래 / 위에 새 줄을 만들고 Insert 모드 시작

dw커서부터 다음 단어 시작까지 삭제

cw커서부터 단어 끝까지 삭제하고 바로 Insert 모드로 (수정할 때 가장 유용)
yy현재 줄 복사 (잘라내지 않음)
p / P복사/삭제한 내용을 커서 뒤 / 앞에 붙여넣기
u방금 한 일 되돌리기 (undo) — 여러 번 누르면 더 이전으로

저장·종료·검색·치환

콜론(:)으로 시작하는 명령들

명령동작
:w저장
:q종료 (저장 안 한 변경이 있으면 거부됨)
:wq 또는 :x저장하고 종료
:q!저장하지 않고 강제 종료 (실수로 망쳤을 때)
/찾을말 + Enter아래쪽으로 검색
:%s/old/new/g문서 전체에서 old를 new로 전부 치환
:%s/old/new/gc치환할 때마다 확인(y/n)을 물어봄 — 안전하게 바꿀 때

산문 쓰기에 유용한 팁

소설 원고 작업에서 특히 쓸 만한 것들

단어 수 세기

Normal 모드에서 g 다음 Ctrl-g — 화면 아래에 줄 수·단어 수·글자 수가 뜬다.

자동 줄바꿈 보기

:set wrap linebreak — 긴 문장이 화면 끝에서 단어 중간이 아니라 단어 단위로 꺾여 보인다. 파일 내용 자체는 바뀌지 않는다 (보이는 방식만 바뀜).

두 줄 합치기

Normal 모드에서 J — 현재 줄과 다음 줄을 한 줄로 합친다. 문단을 다시 다듬을 때 유용.

한글 입력

Insert 모드에서는 평소 쓰는 한글 입력기가 그대로 작동한다. Vim 쪽에서 따로 설정할 게 없다.

막혔을 때

자주 만나는 상황과 탈출법

상황해결
화면에 이상한 글자가 찍히거나 명령이 안 먹힐 때Esc를 눌러 Normal 모드로 돌아간 뒤 다시 시도
:wq를 쳤는데 안 꺼질 때아직 Insert 모드였을 수 있다 — Esc를 먼저, 그다음 :wq
실수로 문단을 통째로 지웠을 때u를 눌러 되돌리기. 여러 번 누르면 계속 이전으로 돌아간다
저장 없이 그냥 나가고 싶을 때 (연습 중 실수했을 때):q! 입력
지금 몇 번째 줄인지 모를 때Normal 모드에서 Ctrl-g — 화면 아래에 현재 줄 번호가 뜬다
