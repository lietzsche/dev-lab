# Level 2. 파일 검색과 텍스트 처리

## 목표
- IDE의 전체 검색이 없어도 터미널에서 Java 소스 파일과 설정 파일을 즉시 찾아낸다.
- 대용량 Spring Boot 애플리케이션 로그와 HTTP 접근 로그에서 원하는 오류·요청·통계를 추출한다.
- 파이프(`|`)와 리다이렉션(`>`, `>>`)으로 여러 명령어를 연결해 실무 데이터 처리 파이프라인을 구성한다.

---

## 세션 구성 (각 15~20분)

### Session 2.1: 파일 이름과 조건으로 탐색 (`find`)
- **실습 목표**: `playground/java-project`와 `playground/files`에서 조건에 맞는 파일과 디렉터리를 찾는다.
- **다루는 명령어**:
  - `find <경로> -name "<패턴>"`: 이름 패턴으로 파일/폴더 검색 (대소문자 구분 없이는 `-iname`)
  - `find <경로> -type f` / `-type d`: 일반 파일 또는 디렉터리만 필터링
- **실습 과제**:
  1. `playground/java-project` 아래의 모든 `.java` 파일 목록 찾기
  2. 이름에 `Controller`가 포함된 클래스 파일만 찾기
  3. `playground/files` 아래에서 확장자가 `.yml`인 설정 파일만 모두 찾기

### Session 2.2: 텍스트 패턴 검색의 표준 (`grep`)
- **실습 목표**: 로그 파일과 Java 소스 코드에서 특정 키워드, 에러, 어노테이션이 있는 줄을 찾는다.
- **다루는 명령어**:
  - `grep "패턴" 파일`: 일치하는 줄 출력
  - `-n` (줄 번호), `-i` (대소문자 무시), `-r` (하위 디렉터리 재귀 검색)
  - `-C 2` / `-A 2` / `-B 2`: 매칭된 줄 전후 맥락(Context) 함께 확인 (스택트레이스 확인 시 필수)
  - `-v` (일치하지 않는 줄만 출력), `-E` (확장 정규표현식 `ERROR|WARN`)
- **실습 과제**:
  1. `playground/logs/app-2026-10-21.log`에서 `ERROR`가 포함된 줄과 줄 번호(`-n`) 출력하기
  2. `ERROR` 발생 지점의 전후 2줄(`-C 2`)을 함께 출력해 예외 원인과 스택트레이스 확인하기
  3. `grep -rn "@Transactional" playground/java-project/`로 트랜잭션이 선언된 코드 위치 찾기

### Session 2.3: 초고속 코드 검색 도구 (`rg` / `ripgrep`)
- **실습 목표**: `.gitignore`를 자동 반영하는 `rg`를 사용해 Java 프로젝트를 빠르게 탐색한다.
- **다루는 명령어**:
  - `rg "패턴" <경로>`: 줄 번호와 파일명을 보기 좋게 하이라이팅하여 재귀 검색
  - `rg -t java "패턴"`: Java 파일만 대상으로 검색
  - `rg -l "패턴"`: 매칭되는 내용이 있는 파일 경로만 출력
  - `rg "TODO|FIXME"`: 코드 내 미해결 작업 주석 검색
- **실습 과제**:
  1. `playground/java-project`에서 `ERR_PAYMENT_TIMEOUT` 에러 코드가 정의·사용된 모든 위치 찾기
  2. `rg -t java "OrderRepository"`로 리포지토리를 참조하는 Java 클래스만 찾기
  3. 프로젝트 내 남아 있는 `TODO` 또는 `FIXME` 주석 한 번에 모아보기

### Session 2.4: 파이프와 리다이렉션 (`|`, `>`, `>>`, `2>`)
- **실습 목표**: 명령어의 출력을 다른 명령어의 입력으로 전달하거나 별도 리포트 파일로 저장한다.
- **다루는 기술**:
  - `cmd1 | cmd2`: `cmd1`의 표준 출력(stdout)을 `cmd2`의 표준 입력(stdin)으로 연결
  - `>` (덮어쓰기 저장), `>>` (이어쓰기 저장), `2>/dev/null` (권한 오류 등 표준 에러 메시지 숨기기)
- **실습 과제**:
  1. `app-2026-10-21.log`에서 `ERROR` 줄만 추출해 `playground/files/temp/error-summary.txt`로 저장하기 (`>`)
  2. `app-2026-10-20.log`의 `ERROR` 줄을 같은 파일 끝에 추가로 이어쓰기 (`>>`)
  3. 저장된 파일의 마지막 5줄만 파이프(`| tail -n 5`)로 확인하기

### Session 2.5: 줄 수 집계와 중복 제거·정렬 (`wc`, `sort`, `uniq`)
- **실습 목표**: 로그 건수를 세고, 가장 많이 발생한 오류나 요청 IP 순위를 집계한다.
- **다루는 명령어**:
  - `wc -l`: 줄 수(Line count) 집계
  - `sort`, `sort -n` (숫자 정렬), `sort -r` (역순 정렬)
  - `uniq`, `uniq -c` (연속된 중복 항목 제거 및 빈도수 카운트 — 반드시 `sort` 후 사용)
- **실습 과제**:
  1. `grep "ERROR" playground/logs/app-2026-10-21.log | wc -l`로 당일 에러 총 건수 세기
  2. `sort`와 `uniq -c`, `sort -nr`를 조합해 중복 데이터를 빈도순으로 정렬하기

### Session 2.6: 필드 추출과 텍스트 가공 (`cut`, `sed`, `awk` 기초)
- **실습 목표**: 정형화된 로그나 CSV 파일에서 원하는 열(Column)만 뽑아내고 문자열을 치환한다.
- **다루는 명령어**:
  - `cut -d '구분자' -f 필드번호`: CSV나 구분자 기반 텍스트에서 특정 열 추출
  - `awk '{print $1, $4}'`: 공백으로 구분된 로그에서 원하는 순서의 컬럼 출력 및 조건 필터링
  - `sed 's/기존/변경/g'`: 스트림 텍스트 치환
- **실습 과제**:
  1. `cut -d ',' -f 1,3 playground/files/server-inventory.csv`로 서버명과 IP 목록만 추출하기
  2. `awk`로 `playground/logs/access.log`에서 클라이언트 IP(`$1`)와 HTTP 상태 코드(`$6`)만 출력하기
  3. `sed`를 사용해 설정 파일의 포트 번호나 환경 이름을 화면에서 치환해 미리 확인하기

### Session 2.7: 실전 조합 — Java 코드 및 장애 로그 분석 파이프라인
- **실습 목표**: Level 1~2에서 배운 명령어들을 파이프로 연결해 실무 질문을 단 한 줄의 명령어로 해결한다.
- **실습 과제**:
  1. `access.log`에서 가장 많이 요청을 보낸 상위 3개 IP 주소와 요청 횟수 추출하기
  2. `app-2026-10-21.log`에서 `ERROR` 로그의 에러 코드만 뽑아 유형별 발생 건수 집계하기
  3. `java-project`에서 발견한 에러 코드가 실제 어느 Java 클래스의 몇 번째 줄에서 던져지는지 추적하기
