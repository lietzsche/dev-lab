# Level 1. Bash와 터미널 조작

## 목표
- 마우스와 파일 탐색기 없이 터미널에서 디렉터리를 빠르게 이동하고 파일을 생성·복사·이동·삭제한다.
- 설정 파일과 애플리케이션 로그의 앞/뒤/전체를 목적에 맞는 명령어로 빠르게 읽는다.
- 줄 편집 단축키와 자동완성, 히스토리를 활용해 오타 수정과 반복 입력 시간을 단축한다.

---

## 세션 구성 (각 10~15분)

### Session 1.1: 현재 위치 확인과 디렉터리 탐색 (`pwd`, `ls`, `cd`)
- **실습 목표**: 작업 디렉터리 위치를 확인하고 `playground` 내부 구조를 탐색한다.
- **다루는 명령어**:
  - `pwd`: 현재 작업 디렉터리(Print Working Directory) 절대 경로 확인
  - `ls`, `ls -l`, `ls -la`, `ls -lh`: 파일 목록, 상세 권한/크기, 숨김 파일, 읽기 쉬운 용량 단위 출력
  - `cd`: 상대 경로(`playground`, `..`), 홈 디렉터리(`~`), 직전 디렉터리(`cd -`) 이동
- **실습 과제**:
  1. `pwd`로 현재 경로 확인하기
  2. `ls`와 `ls -la`로 프로젝트 루트 구성 비교하기
  3. `cd playground`로 이동 후 하위 폴더(`files`, `java-project`, `logs`, `scripts`) 확인하기
  4. `cd -`와 `cd ..`로 빠르게 왕복 이동하기

### Session 1.2: 디렉터리와 파일 생성 (`mkdir`, `touch`, `Tab` 자동완성)
- **실습 목표**: `Tab` 자동완성으로 타이핑을 줄이며 중첩 디렉터리와 빈 파일을 만든다.
- **다루는 명령어**:
  - `Tab` / `Tab 두 번`: 경로 및 파일명 자동완성과 후보 목록 확인
  - `mkdir`, `mkdir -p`: 단일 디렉터리 및 상위 경로를 포함한 중첩 디렉터리 일괄 생성
  - `touch`: 빈 파일 생성 및 타임스탬프 갱신
- **실습 과제**:
  1. `Tab` 키를 사용해 `playground/files`로 이동하기
  2. `mkdir -p work/2026-10/drafts`로 중첩 폴더 한 번에 생성하기
  3. `touch work/2026-10/drafts/release-note.md`로 빈 파일 생성 후 `ls -l`로 확인하기

### Session 1.3: 파일 복사, 이동/이름 변경, 안전 삭제 (`cp`, `mv`, `rm`)
- **실습 목표**: 설정 파일을 백업·복사하고 임시 파일을 정리한다.
- **다루는 명령어**:
  - `cp`, `cp -r`: 파일 및 디렉터리 복사 (수정 전 `.bak` 백업 생성 습관)
  - `mv`: 파일/디렉터리 위치 이동 및 이름 변경
  - `rm`, `rm -i`, `rm -r`: 파일 및 디렉터리 삭제
- **실습 과제**:
  1. `playground/files/config/application.yml`을 `application.yml.bak`으로 복사하기 (`cp`)
  2. 생성한 백업 파일을 `playground/files/backup/` 디렉터리로 이동하기 (`mv`)
  3. `playground/files/temp/` 안의 연습용 임시 파일을 삭제하고 확인하기 (`rm`)

### Session 1.4: 파일과 로그 내용 읽기 (`cat`, `head`, `tail`, `less`)
- **실습 목표**: 파일 크기에 따라 적절한 조회 도구를 선택해 설정과 로그를 읽는다.
- **다루는 명령어**:
  - `cat`, `cat -n`: 짧은 설정 파일 전체 출력 및 줄 번호 표시
  - `head -n`: 파일의 처음 N줄 확인
  - `tail -n`, `tail -f`: 로그 파일의 마지막 N줄 및 실시간 추가 로그 감시
  - `less`: 긴 로그 파일을 페이지 단위로 스크롤(`Space`, `b`, `g`, `G`)하고 키워드(`/ERROR`, `n`, `N`)로 탐색 후 종료(`q`)
- **실습 과제**:
  1. `cat -n playground/files/config/application.yml`로 설정 파일 내용 확인하기
  2. `head -n 5`와 `tail -n 10`으로 `playground/logs/app-2026-10-21.log`의 시작과 끝 확인하기
  3. `less playground/logs/app-2026-10-21.log`로 열어 `/ERROR` 검색 후 `q`로 빠져나오기

### Session 1.5: 터미널 커서 이동과 줄 편집 단축키
- **실습 목표**: 방향키를 연타하지 않고 단축키로 명령어 줄을 즉시 수정한다.
- **다루는 단축키**:
  - `Ctrl+A` / `Ctrl+E`: 줄 맨 앞으로 / 맨 뒤로 이동
  - `Ctrl+W`: 커서 앞의 한 단어 삭제
  - `Ctrl+U` / `Ctrl+K`: 커서 앞 전체 삭제 / 커서 뒤 전체 삭제
  - `Ctrl+L`: 터미널 화면 깔끔하게 지우기 (`clear` 대체)
- **실습 과제**:
  1. 긴 경로 조회 명령어를 입력한 상태에서 `Ctrl+A`, `Ctrl+E`로 커서 이동 연습하기
  2. `Ctrl+W`로 마지막 인자만 지우고 다른 파일명으로 바꿔 실행하기
  3. `Ctrl+U`로 입력 중인 명령을 취소하고 `Ctrl+L`로 화면 정리하기

### Session 1.6: 명령어 히스토리와 와일드카드 (`history`, `Ctrl+R`, `*`, `?`)
- **실습 목표**: 이전에 실행한 명령어를 즉시 재호출하고 패턴 매칭으로 여러 파일을 한 번에 다룬다.
- **다루는 기술**:
  - `history`: 실행했던 명령어 목록 확인
  - `Ctrl+R`: 역방향 증분 검색(Reverse-i-search)으로 과거 명령어 즉시 찾기
  - `*`, `?`, `{a,b}`: 와일드카드(Globbing)와 중괄호 확장으로 다중 파일 매칭
- **실습 과제**:
  1. `Ctrl+R`을 눌러 이전에 실행한 `application.yml` 관련 명령어를 찾아 실행하기
  2. `ls playground/logs/*.log`로 로그 파일만 필터링해 출력하기
  3. `ls playground/files/config/application-*.yml`로 환경별 설정 파일만 조회하기
